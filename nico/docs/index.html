Documentación de Integración

Aprende cómo agregar a Nico a tu sitio web en pocos minutos

1 Obtén tus credenciales

Después de completar tu pago con Corox, recibirás un correo con tus credenciales:

  • businessId: Identificador único de tu negocio
  • channelId: Canal de atención configurado
Nota: Si no has recibido tus credenciales, contacta a info@corox.click

2 Descarga los archivos

Descarga los archivos del widget y agrégalos a tu proyecto:

  • nico-widget.umd.js - Script principal
  • style.css - Estilos del widget

Copia estos archivos desde la carpeta /nico a tu servidor o CDN.

3 Agrega el código a tu HTML

Pega este código en tu página HTML, antes de cerrar el tag </body>: 

<!-- 1. Incluye los archivos -->
<script src="ruta/a/nico-widget.umd.js"></script>
<link rel="stylesheet" href="ruta/a/style.css" />

<!-- 2. Contenedor del widget -->
<div id="nico-widget-container"></div>

<!-- 3. Inicializa Nico -->
<script>
  window.createNicoWidget("nico-widget-container", {
    businessId: "TU_BUSINESS_ID",
    channelId: "TU_CHANNEL_ID",
    apiUrl: "https://api.corox.click/api/v1/widget",
    primaryColor: "#a52a2a"
  });
</script>
Importante: Reemplaza TU_BUSINESS_ID y TU_CHANNEL_ID con los valores que recibiste por correo.

4 Personaliza (opcional)

Puedes modificar la apariencia del widget con estas opciones:

Opción Tipo Descripción
position string Posición: "bottom-right" o "bottom-left"
title string Título del chat (ej: "Nico - Asistente")
welcomeMessage string Mensaje de bienvenida inicial
primaryColor string Color principal en formato HEX
finalGradient string Color degradado final (para acentos)

Ejemplo con personalización: 

window.createNicoWidget("nico-widget-container", {
  businessId: "TU_BUSINESS_ID",
  channelId: "TU_CHANNEL_ID", 
  apiUrl: "https://api.corox.click/api/v1/widget",
  position: "bottom-left",
  title: "🧑‍🍳 Nico - Tu Chef Virtual",
  welcomeMessage: "¡Hola! Soy Nico, ¿qué te gustaría pedir hoy?",
  primaryColor: "#e67e22",
  finalGradient: "#f39c12"
});

5 Proveedor LLM Personalizado

Si ya cuentas con tu propio proveedor de modelos de lenguaje (LLM) como OpenAI, Anthropic o un modelo local, puedes integrarlo fácilmente con Nico. Esto te permite mantener el control total sobre tus modelos, datos y costos.

Configuración: Para integrar un proveedor personalizado, contacta a nuestro equipo técnico para habilitar la pasarela de comunicación en tu instancia de Nico.
